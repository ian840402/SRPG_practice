# 原型目標

## 主要目標

建立一個小型 2D 戰棋 RPG 原型，優先驗證核心戰鬥邏輯與 C# / OOP 設計練習。

第一版暫不追求動畫、美術、音效或完整平衡。

## 文件命名規則

- `grid`：用於座標、距離、鄰接、範圍與目標解析。
- `tile`：用於地形、移動成本、地形效果與地圖格資料。
- 中文「格」只保留在玩家規格或自然語句中；工程規格優先明確寫成 `grid` 或 `tile`。

## 六階段路線圖

### 1. 基礎戰棋操作

- 目標：建立可點擊棋盤、單位、移動、攻擊、敵方回合與勝敗判定。
- 狀態：已完成。

### 2. 多單位與回合流程

- 目標：支援多個單位、明確回合狀態、移動後攻擊與基礎 UI 回饋。
- 狀態：已完成。

### 3. 最小職業戰鬥模型

- 目標：建立戰士、弓箭手、法師的最小職業差異，包含普通攻擊、範圍攻擊、主動技能、被動技能、方向性、狀態效果與該階段 AI 補強。
- 狀態：進行中。

### 4. 最小關卡模型

- 目標：加入 tile 地形成本、簡易地形效果、非對稱關卡數值，以及三種關卡目標。
- 預計包含：
  - tile 地形成本與簡易地形效果。
  - 簡易關卡資料結構。
  - 簡易關卡數值設計。
  - 三種過關條件：殲滅戰、到達指定地點、打倒指定目標。
  - 三張對應測試地圖。
  - 該階段 AI 行為補強。
- 驗收：
  - 殲滅戰原型：擊敗所有敵人即可過關。
  - 到達指定地點原型：指定玩家單位抵達目標 grid 座標即可過關。
  - 打倒指定目標原型：擊敗指定 boss / 目標敵人即可過關。

### 5. 最小表現層

- 目標：加入簡易美術、動畫與音效，讓 prototype 更接近可 playtest 的遊戲體驗。
- 不追求正式美術品質。

### 6. 最小遊戲入口

- 目標：加入簡易初始化選單，開啟遊戲後可選擇關卡遊玩。
- 完成後，此專案可視為最小遊戲 prototype。

## 後續待辦

### 7. Grid 範圍與目標解析整理

- 集中常用 grid 操作，供移動範圍、攻擊範圍與技能範圍共用。
- 可取得上下左右相鄰 grid。
- 可取得 Manhattan distance 範圍內 grid。
- 可取得十字範圍 grid。
- 可過濾棋盤外 grid。
- 現有移動與普通攻擊行為不變。

### 8. 範圍攻擊原型

- 可選一個目標 grid。
- 目標 grid 加上下左右各 1 個 grid 形成十字範圍。
- 範圍內所有敵人受到傷害。
- 空 grid 忽略。
- 第一版不影響友軍。
- 不先處理 MP 與法師技能選單。

### 9. 法師 MP 與技能選擇

- 法師普通攻擊維持可用。
- 單體法術：消耗 3 MP，射程 3，造成 `法師攻擊 + 4`，無視防禦，不命中判定，不暴擊。
- 十字法術：消耗 4 MP，射程 3，造成 `法師攻擊 + 1`，無視防禦，不命中判定，不暴擊。
- MP 不足時不能使用技能。

### 10. 單位方向性

- 每個單位有面向方向，例如 Up、Down、Left、Right。
- 單位移動後，面向可先自動設為最後移動方向。
- 待機時第一版先保留目前面向，不做選方向 UI。
- 可判斷攻擊者是否位於目標背後。
- 不先做背刺傷害加成、側襲規則或方向性動畫。

### 11. 簡易被動技能

- 單位可以持有被動技能識別。
- 戰鬥公式或行動規則可以查詢被動技能。
- 至少實作 1-2 個簡單被動效果。
- 可優先驗證背刺類被動。
- 不做大型被動技能 UI、複雜觸發條件或堆疊規則。

### 12. 狀態效果基礎

- 單位可持有狀態效果。
- 同一狀態不堆疊；重新套用時重置持續時間。
- 狀態立即套用，在持有者回合結束時遞減，剩餘 0 時移除。

### 13. 第三階段 AI 行為補強

- 敵人會選擇可攻擊目標。
- 優先攻擊可擊殺目標。
- 沒有可擊殺目標時，優先攻擊低 HP 或最近目標。
- 敵人移動不會因直接路徑被佔用就停止。
- 敵人會嘗試移動到能攻擊目標的位置。
- 敵人移動使用目前 BFS / 移動範圍規則。
- 若已有技能或範圍攻擊，敵人至少不會選擇完全無效的技能。
- 不做完整 utility AI、地形策略、關卡目標策略或長期規劃。

### 14. 第三個可玩目標驗證

- `dotnet format SRPG_practice.sln --verify-no-changes` 通過。
- `dotnet build SRPG_practice.sln` 成功。
- 可用既有資料結構新增一個測試職業。
- 可用既有資料結構新增一個測試單位，並配置到戰鬥中。
- 新增職業至少能設定 HP、MP、攻擊、防禦、命中、迴避、移動力、暴擊率、普通攻擊射程、主動技能與被動技能。
- 新增職業不需要修改核心移動、攻擊、技能、狀態效果或 AI 流程；若仍需修改，記錄為第四階段前的架構整理項目。
- `docs/LOG.md` 記錄已驗證內容與後續平衡/AI 工作。
