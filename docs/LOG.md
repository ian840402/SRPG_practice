- 已完成 6D：行動模式已移出 `Unit`，改由玩家操作流程保存。

## 已完成摘要

### 基礎原型

- 建立 8x8 棋盤與基本點擊解析。
- 顯示玩家與敵方單位。
- 支援玩家選取、移動、攻擊與簡單狀態文字。
- 支援敵方簡單回合。
- 支援勝利與失敗判定。

### 第二個可玩目標

- 新增明確的 `GameState`。
- 支援多個玩家與敵方單位。
- 玩家單位可保留剩餘移動點，移動後仍可攻擊。
- 單位 HP 直接顯示在棋盤上。
- 選取玩家單位時顯示有效移動格。
- 拆分核心狀態、規則、resolver 與 rendering 職責。

### 第三個可玩目標進度

- 新增戰士、弓箭手、法師職業資料。
- 單位數值從職業定義推導。
- 普通攻擊支援最小與最大射程。
- 普通攻擊公式包含命中、迴避、暴擊與最低傷害。
- 選取單位時顯示 HP、MP、職業、攻防、命中/迴避、暴擊與射程資訊。
- 新增單位待機狀態與可行動推導屬性。
- 可用鍵盤切換查看、移動、攻擊與待機模式。
- 可移動範圍已從 Manhattan distance 篩選改為 BFS：
  - 敵軍阻擋路徑。
  - 友軍可穿越。
  - 實際移動使用 BFS 結果與距離扣移動點。
- 行動模式已從 `Unit` 移到玩家操作流程：
  - `Unit` 不再持有目前行動模式。
  - 移動/攻擊模式下點擊友軍不會切換選取單位。
  - 新增 Escape 返回選取狀態。
- 攻擊模式會顯示普通攻擊範圍：
  - 戰士與法師顯示相鄰格。
  - 弓箭手顯示距離 2-3 格，不包含相鄰格。
  - 攻擊範圍使用紅色高亮，並與實際攻擊判定共用範圍資料。
